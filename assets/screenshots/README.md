**Guidelines**

- Real screenshots only — no mockups presented as shipped functionality.
- PNG, or WebP under ~250KB each.
- Use seeded demo data. Check no real phone numbers, emails, bank details or
  payment keys are visible before committing — this repository is public.
- Consistent device frame and background across all images.
